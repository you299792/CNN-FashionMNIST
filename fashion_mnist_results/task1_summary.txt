Fashion-MNIST data plan
=====================
Task statement: Multi-class clothing image classification using Fashion-MNIST. Input size: 32x32 grayscale images (converted from 28x28 source). Number of classes: 10.
Splits: train/validation/test = 48,000 / 6,000 / 10,000 images.
Preprocessing: normalize to [0,1], resize from 28x28 to 32x32, and use one-hot labels only at the model output.
